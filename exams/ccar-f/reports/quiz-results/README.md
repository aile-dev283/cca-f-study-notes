# quiz-results — 演習結果の置き場

`cca-f-trainer` スキルが生成した `banks/<バンク名>/quiz.html` を解いたあと、
**「Download Results (JSON)」でダウンロードしたファイルをこのフォルダに置く。**

ファイル名の規約: `<バンク名>-results-<タイムスタンプ>.json`

## なぜ置く必要があるか

次にバンクを作るとき **focus に「弱点ターゲット」を選ぶと、このフォルダ内の全 JSON を自動集計して**
task_statement 別の誤答率から優先出題を決める。**ここが空だと弱点ターゲットは発火せず、横断出題にフォールバックする。**

> 2026-08-08 の本試験（580点・不合格）の事後分析では、このフォルダが**そもそも存在しておらず**、
> 弱点ターゲット生成が一度も発火していなかったことが敗因の1つとして特定された。
> 詳細: [CCAR-F_ExamAttempt1_Analysis_2026-08-09.md](../CCAR-F_ExamAttempt1_Analysis_2026-08-09.md) §4「欠陥4」

## 運用ルール

1. **解いたら必ず保存する。** 解きっぱなしにしない。
2. 途中でやめた場合も保存してよい（`answered` に未回答数が入る）。
3. 消さない。時系列で溜めるほど、直近の誤答に重みを付けた優先度計算が正確になる。

## コミット方針

演習結果は個人の学習記録のため **gitignore 済み**（この README だけが追跡対象）。
チームで共有されるのは `.claude/skills/cca-f-trainer/banks/` の問題バンクのみ。
