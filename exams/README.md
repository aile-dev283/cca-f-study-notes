# exams/

Anthropic Claude Certification Program の Exam Guide（試験ごとの公式PDF・Markdown化・受験記録）を配置するディレクトリ。

Anthropicの認定制度は現在4種類の姉妹認定に分かれている（2026年7月施行 Version 1.0 ガイドより）。

| Exam code | 正式名称 | 対象 | このリポジトリでの扱い |
|---|---|---|---|
| **[CCAR-F](ccar-f/)** | Claude Certified Architect – Foundations | Claude API / Agent SDK / Claude Code / MCP でプロダクションシステムを設計するアーキテクト | ✅ 本リポジトリのメイン対象。Exam Guide Markdown化・問題演習に対応 |
| [CCAR-P](ccar-p/) | Claude Certified Architect – Professional | CCAR-F 相当のプロフェッショナル向け | 参考PDFのみ |
| [CCAO-F](ccao-f/) | Claude Certified Associate – Foundations | Claude を業務・生産性タスクに活用する一般利用者 | 参考PDFのみ |
| [CCDV-F](ccdv-f/) | Claude Certified Developer – Foundations | Claude でアプリケーション・エージェントを実装するデベロッパー | 参考PDFのみ |

このリポジトリ（`cca-f-study-notes`）は元々単一の「CCA-F」試験を対象に作られたが、試験制度が4種類に分かれたことで対象試験の正式コードが **CCAR-F** であることが確定した。学習コンテンツ（[`study/`](../study/)）・問題演習トレーナー（`.claude/skills/cca-f-trainer/`）は引き続き CCAR-F にのみ対応する。
